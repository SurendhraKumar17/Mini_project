How the analysis works

The dashboard compares shipping details with delivery results. You do not need to understand the technical method to use the charts above.

1. IngestDataCo CSV is parsed in a Web Worker so the UI remains responsive.
2. MinePython mlxtend.fpgrowth finds itemsets at minimum support 0.3%.
3. Filterassociation_rules keeps delayed-outcome rules at minimum confidence 60%.
4. ExplainSupport shows prevalence; confidence shows delay likelihood; lift compares with baseline delay rate.
